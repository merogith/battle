# Kenney Interface Sounds

Kenney Vleugels’s CC0 1.0 effects are staged from `kenney_interfaceSounds.zip`, as published by the creator. The selected Ogg files match the archive payloads. [Creator upload](https://opengameart.org/content/interface-sounds) · [Pack page](https://kenney.nl/assets/interface-sounds) · [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)

| Original path in pack | Planned use |
| --- | --- |
| `Audio/click_001.ogg` | Optional activation feedback on a deliberate action. |
| `Audio/confirmation_001.ogg` | A committed utility or selection with a matching receipt. |
| `Audio/error_001.ogg` | Optional feedback on a blocked action with a visible reason. |
