## Useful context for any of these

- Harness: `tests/helpers/load-engine.js` (jsdom, ~2.5s first boot, cached). Exposes
  `mkMon`, `runTurn`, `reset`, `seedRng`, `engine`, `window`. **`runTurn` re-seeds to
  `seedRng(0)` every call** → deterministic. For accuracy-gated moves, sweep seeds
  (manual `reset()` + `seedRng(seed)` + `window.playTurn`); see
  `_drafts/status-infliction.test.js` for the pattern.
- Skills: `fix-todo-test` (fill a todo cluster → draft), `emit-finding` (file a ledger
  finding with a stable fingerprint), `repro-battle` / `run-engine-test` (deterministic
  repros), `anchor` (resolve a symbol → `file:line`).
- Findings & ledger: `agent-state/findings/test-coverage-filler-*.md`,
  `agent-state/ISSUE_LEDGER.md` (regenerate: `node scripts/debug/issue-ledger.mjs`).
- **Apostrophe gotcha** (cost two tests this pass): the engine matches move names
  exactly. The generator's `safeName` strips apostrophes, so the displayed todo
  `'Kings Shield'` is NOT the engine's `"King's Shield"`. Always use the real name
  (`King's Shield`, `Land's Wrath`, `Forest's Curse`, `Nature's Madness`,
  `Conversion 2`) in `mkMon`. An unknown name silently runs as a ~187-dmg fallback.
